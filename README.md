# NNN Куратор

ҰБТ-ға дайындық курсының кураторына арналған апталық рейтинг сайты. Сайт келесі жұмыстарды жасайды:

- Excel сияқты кестеге баллдарды енгізу. Түс (жасыл / көк / қызыл) пен орын бірден жаңарады.
- АБС / АТ пен ПП (пересдача) беттерін өзі толтырады.
- Ата-аналарға жіберілетін мәтінді әр оқушыға бөлек жазады. Мәтінді көшіруге немесе бірден WhatsApp-та ашуға болады.
- Бір батырмамен 4 файл жасайды: Excel рейтинг (РТ / АБС-АТ / ПП беттері), рейтинг суреті және басшыға арналған PowerPoint отчет.

Сайт компьютерде жұмыс істейді, интернет қажет емес. Деректер компьютердегі папкада сақталады.

## Орнату

1. [Node.js](https://nodejs.org) орнатыңыз (LTS нұсқасы).
2. Репозиторийді жүктеп алыңыз.
3. `NNN Куратор.bat` файлын екі рет басыңыз. Алғашқы рет кітапханалар өздігінен орнатылады (`npm install`).
4. Сайт алғаш ашылғанда **«Қош келдіңіз!»** беті шығады. Онда үш нәрсені толтырасыз:
   - **аты-жөніңіз**: басшыға арналған отчеттың бірінші слайдында шығады;
   - **деректер папкасы**: топтар, баллдар, Excel және отчеттар осында сақталады (әдепкісі `Құжаттар\NNN Куратор`). Өрісті немесе **«Таңдау»** батырмасын басқанда Проводник ашылады, сол жерден папканы таңдайсыз;
   - **телефон PIN-коды**: 6 сан, міндетті емес.

Бұлардың бәрін кейін **Баптаулар → Компьютер** бөлімінде өзгертуге болады.

## Басқа кураторларға беру

Әр куратор сайтты өз компьютерінде қолданады, деректері тек өзінде сақталады.

1. Куратор жоғарыдағы «Орнату» қадамдарын орындайды.
2. «Қош келдіңіз!» бетінде өз аты-жөнін, папкасын және PIN-кодын енгізеді.
3. Өз топтарын ашып, оқушыларын енгізеді.

Сайттың жаңа нұсқасы шыққанда куратор репозиторийді қайта жүктеп, ескі папканың орнына қояды. Тек `config.json` файлын сақтап қалу керек, себебі онда оның папкасы мен PIN-коды тұр. Деректер бөлек папкада тұрғандықтан жоғалмайды.

## Іске қосу

| Файл | Не істейді |
|---|---|
| `NNN Куратор.bat` | Сайтты тек осы компьютерде ашады. |
| `NNN Куратор (телефон).bat` | Сайтты телефоннан да ашуға мүмкіндік береді. Компьютер мен телефон бір Wi-Fi желісінде болуы керек. |

Қара терезе ашық тұрғанша сайт жұмыс істейді. Терезені жапсаңыз, сайт тоқтайды.

### Телефоннан ашу

1. `NNN Куратор (телефон).bat` іске қосыңыз. Windows желіге рұқсат сұраса, **«Рұқсат беру»** басыңыз.
2. Қара терезеде мынадай мекенжай мен PIN-код шығады:
   ```
   http://192.168.x.x:4747
   PIN-код: өзіңіз орнатқан 6 сан
   ```
   PIN-код орнатылмаған болса, қара терезеде жаңа PIN-код бір рет көрсетіледі. Оны жазып алыңыз.
3. Телефондағы браузерде осы мекенжайды ашып, PIN-кодты енгізіңіз. Бір рет енгізсеңіз жеткілікті.
4. Браузер мәзірінен **«Басты экранға қосу»** таңдасаңыз, сайт телефонда қосымша сияқты ашылады.

PIN-код бір Wi-Fi-дағы бөгде адамдардың оқушылар деректерін көруіне жол бермейді. Кафе сияқты қоғамдық Wi-Fi-да телефон режимін қоспаңыз.

## Деректер қайда сақталады

Деректер «Қош келдіңіз!» бетінде таңдалған папкада сақталады. Мысалы, `D:\NNN` таңдалса:

```
D:\NNN\
  nnn-kurator-settings.json        топтар тізімі мен баптаулар
  РТ-МАТ\
    nnn-kurator-data.json          оқушылар және барлық апталардың баллдары
    nnn-kurator-data.backup.json   алдыңғы сақтаудың көшірмесі
    РТ_8_АПТА_МАТ-4.xlsx
    РТ_8_АПТА_МАТ-4.png
    АТ_8_АПТА_МАТ-4.png
    отчет_8_АПТА_МАТ-4.pptx
```

Папка мен PIN-код сайт папкасындағы `config.json` файлында сақталады. PIN-код ашық түрде емес, хеш түрінде жазылады. Бұл файл GitHub-қа жүктелмейді.

Деректер репозиторийге түспейді (`.gitignore`). Оларды қосымша Google Drive немесе флешкаға сақтап отырған дұрыс.

## Құрылымы

```
server.js            жергілікті сервер: деректерді сақтайды, файлдарды папкаға жазады
scripts/pick-folder.ps1  Проводник арқылы папка таңдау терезесі (Windows)
public/index.html
public/css/          дизайн (компьютер + телефон)
public/js/app.js     беттер: топтар, апталар, оқушылар, АБС/АТ, ПП, ата-аналар, отчет
public/js/grid.js    рейтинг кестесі
public/js/calc.js    есептеулер (пайыз, түс, сұрыптау, АБС/АТ кезегі)
public/js/messages.js  ата-ана мәтіндері
public/js/exports.js   Excel, сурет, PowerPoint
public/assets/       логотип, иконкалар, слайд фондары
```
